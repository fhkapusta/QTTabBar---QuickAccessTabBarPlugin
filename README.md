# Плагін «Швидкий доступ та Обране» для QTTabBar (ver 2048 beta 2, Win10)

Плагін додає кнопку зі спадним меню з обраними папками та закріпленими папками Windows Quick Access безпосередньо **на панель вкладок з правого краю** (поруч із вкладками та кнопкою `+`).

---

## 🚀 Можливості

* **Розташування:** Притиснуто до правого краю панелі вкладок (`ToolStripItemAlignment.Right`), не заважає звичайним вкладкам та кнопці `+`.
* **⚡ Швидкий доступ Windows:** Автоматично підтягує реальні закріплені папки з Windows Quick Access (AutomaticDestinations JumpList), папки профілю та стандартні системні директорії.
* **⭐ Користувацьке Обране:** Зберігає власний список папок у `%APPDATA%\QTTabBar\FavoritesPlugin.json`.
* **Додавання поточної папки:** Пункт `➕ Додати поточну папку до Обраного` миттєво додає поточну активну директорію вікна Explorer.
* **Підтримка підпапок:** При наведенні миші на будь-яку папку розгортається підменю з її дочірніми каталогами.
* **Гнучке відкриття:**
  * **Лівий клік:** Відкриває папку в новій активній вкладці.
  * **Клік коліщатком (Middle click):** Відкриває папку у фоновій вкладці.
  * **Shift + Лівий клік:** Відкриває папку в окремому вікні.
  * **Правий клік:** Контекстне меню (нова вкладка, нове вікно, видалити з обраного).
* **Стилізація:** Повністю використовує системний стиль та рендерер QTTabBar (`GetMenuRenderer()`).
* **Вікно налаштувань:** Окреме діалогове вікно керування списком (додавання через огляд, видалення, сортування Вгору/Вниз).

## 📦 Встановлення та активація в QTTabBar

### Крок 1. Дозвіл на сторонні плагіни
У версії QTTabBar 2048 beta 2 за замовчуванням увімкнено перевірку підпису:
1. Відкрийте Провідник Windows (Explorer).
2. Натисніть **Alt + O** (або правий клік по вкладці → **QTTabBar Options**).
3. Перейдіть на вкладку **Plugin**.
4. Встановіть прапорець **[✓] Allow 3rd-party plugins** (або *«Дозволити сторонні плагіни»*).

### Крок 2. Додавання плагіна
1. На вкладці **Plugin** натисніть кнопку **Add...** (Додати).
2. Виберіть файл.
3. У списку з'явиться плагін: **Швидкий доступ та Обране**.
4. Переконайтеся, що біля нього встановлено прапорець (активовано).
5. Натисніть **Apply** або **OK**.

### Крок 3. Перезапуск Explorer
перезапустіть `explorer.exe` через Диспетчер завдань Windows.

Після цього відкрийте будь-яке вікно Explorer — у правому куті панелі вкладок з'явиться кнопка **⭐ Обране ▾**.
